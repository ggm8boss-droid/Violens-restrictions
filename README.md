# Violens-restrictions
violens and vanilla skyrim have limits on killmove activasion, simply gives the ability to change those restrictions, so they will be harder to activate or easier
Vio Restrictions - Wide Target.esp - simple plugin extends the angle and distance of weapon hit
VioLens SE - Height Control.esp - MCM menu with restrictions that can be changed

Requirments:
1. SKSE - https://skse.silverlock.org/
2. SkyUI - https://www.nexusmods.com/skyrimspecialedition/mods/12604
3. JC Containers - https://www.nexusmods.com/skyrimspecialedition/mods/16495?tab=files
4. vioLens - https://www.nexusmods.com/skyrimspecialedition/mods/668
installation instructions will be found in the URLs or install through a mod manager vortex or MO2
Vortex - https://www.nexusmods.com/vortex
MO2 - https://www.nexusmods.com/skyrimspecialedition/mods/6194
